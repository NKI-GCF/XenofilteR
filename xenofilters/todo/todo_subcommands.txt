## Evaluation

**Current pain points the flat interface creates:**

- `--matching-algorithm` is buried; a new user does not know it exists without reading full `--help`
- Flags only valid for one algorithm appear in all three contexts: `--score-threads` is meaningless for `hashlookup`; `--ambiguous-regions` is meaningless for `namesorted`; `--threads 1` is forced for `hashlookup` but silently accepted in the CLI
- Validation errors appear at runtime rather than at parse time
- Shell completion for e.g. `zsh` / `fish` works far better with subcommands (each subcommand gets its own completion context)

**Arguments against subcommands:**

- Breaking change: all existing scripts using `--matching-algorithm` break
- The three algorithms are meant to be *equivalent* in output — subcommands imply more fundamental semantic differences than exist
- Shared flags (`--gap-open`, `--sample-variants`, `--output`, etc.) must be duplicated or hoisted into a parent struct, adding indirection

**Verdict:** Subcommands are the right structure. The algorithm differences are real enough (sort order requirements, thread constraints, region-file formats) to warrant first-class CLI visibility. Breaking change is acceptable with a transition period.

Migration strategy: keep `--matching-algorithm` as a deprecated hidden alias that internally constructs the equivalent subcommand.

```rust
use clap::{Args, Parser, Subcommand};
use crate::penalty::ErrorModel;
use std::path::PathBuf;

// ── Top-level CLI ─────────────────────────────────────────────────────────────

/// Fast multi-stream read classifier for xenograft, PDX, viral integration,
/// and cross-species sequencing experiments.
#[derive(Parser, Debug)]
#[command(
    author, version,
    about = "Disambiguate reads from multi-species sequencing experiments",
    long_about = None,
    subcommand_required = true,
    arg_required_else_help = true,
)]
pub(crate) struct Cli {
    #[command(subcommand)]
    pub(crate) command: AlgorithmCommand,
}

#[derive(Subcommand, Debug)]
pub(crate) enum AlgorithmCommand {
    /// Disambiguate name-sorted BAM/CRAM streams (default for most pipelines).
    ///
    /// All input files must be sorted by query name in identical order.
    /// Supports up to 32 simultaneous alignment streams, parallel scoring,
    /// chimeric-pair detection, and stdin BAM input.
    Namesorted(NamesortedArgs),

    /// Disambiguate coordinate-sorted BAMs without re-sorting.
    ///
    /// Two-pass algorithm: pass 1 indexes fragment names via BGZF virtual
    /// offsets; pass 2 retrieves and emits records in driving-stream order.
    /// Requires exactly 2 BAM streams. Single-threaded. In-memory BED/VCF
    /// region files force full NW scoring on overlapping reads.
    Hashlookup(HashlookupArgs),

    /// Disambiguate collated BAM streams (records grouped by name, any order).
    ///
    /// Each input BAM must be collated (all records for a fragment contiguous)
    /// but the two streams need not present fragments in the same order.
    /// Requires exactly 2 streams. Supports tabix-indexed BED/VCF regions.
    Collated(CollatedArgs),
}

impl AlgorithmCommand {
    /// Extract the common args regardless of which subcommand was chosen.
    pub(crate) fn common(&self) -> &CommonArgs {
        match self {
            AlgorithmCommand::Namesorted(a) => &a.common,
            AlgorithmCommand::Hashlookup(a) => &a.common,
            AlgorithmCommand::Collated(a)   => &a.common,
        }
    }
    pub(crate) fn common_mut(&mut self) -> &mut CommonArgs {
        match self {
            AlgorithmCommand::Namesorted(a) => &mut a.common,
            AlgorithmCommand::Hashlookup(a) => &mut a.common,
            AlgorithmCommand::Collated(a)   => &mut a.common,
        }
    }
}
```

### `src/main.rs` — dispatch on subcommand

```rust
fn main() -> Result<(), Error> {
    let mut cli = Cli::parse();
    init_tracing(cli.command.common().verbose, cli.command.common().quiet);

    // Validate common args, detect pass 2, resolve thresholds.
    validate_common(cli.command.common_mut())?;

    match cli.command {
        AlgorithmCommand::Namesorted(args) => run_namesorted(args),
        AlgorithmCommand::Hashlookup(args) => run_hashlookup(args),
        AlgorithmCommand::Collated(args)   => run_collated(args),
    }
}

fn run_namesorted(mut args: NamesortedArgs) -> Result<(), Error> {
    let n = args.common.alignment.len();
    ensure!(n >= 1, "namesorted requires at least 1 alignment stream");
    ensure!(n <= MAX_STREAMS,
        "namesorted supports at most {MAX_STREAMS} streams (got {n})");

    // Parse chimeric pairs
    args.common.parsed_chimeric_pairs =
        parse_chimeric_pairs(&args.chimeric_pairs, n)?;

    let aln = open_streams_unified(&mut args.common, args.threads)?;
    let counters = if args.score_threads > 1 {
        LineByLine::new_from_namesorted(&args, aln)?.process_parallel()?
    } else {
        LineByLine::new_from_namesorted(&args, aln)?.process_sequential()?
    };
    print_routing_counters(&counters, "namesorted", &args.common);
    write_stats_if_configured(&counters, &args.common, n, "namesorted")
}

fn run_hashlookup(mut args: HashlookupArgs) -> Result<(), Error> {
    let n = args.common.alignment.len();
    ensure!(n == 2, "hashlookup requires exactly 2 alignment streams (got {n})");

    let header_name_to_id = open_first_header_name_to_id(&args.common)?;
    let bed = load_ambiguous_regions_memory(&args.ambiguous_regions, &header_name_to_id)?;
    let vcf = load_diagnostic_variants_memory(&args.diagnostic_variants, &header_name_to_id)?;
    let pos = load_positive_regions_memory(&args.positive_regions, &header_name_to_id,
                                           args.region_score_fn)?;
    let aln = open_streams_raw_bam(&mut args.common)?;
    let counters = HashLookup::new_from_hashlookup(&args, aln, bed, vcf, pos)?.process()?;
    print_routing_counters(&counters, "hashlookup", &args.common);
    write_stats_if_configured(&counters, &args.common, n, "hashlookup")
}

fn run_collated(mut args: CollatedArgs) -> Result<(), Error> {
    let n = args.common.alignment.len();
    ensure!(n == 2, "collated requires exactly 2 alignment streams (got {n})");

    let bed = open_tabix_bed(&args.ambiguous_regions)?;
    let vcf = open_tabix_vcf(&args.diagnostic_variants)?;
    let pos = open_tabix_scored(&args.positive_regions, args.region_score_fn)?;
    let aln = open_streams_unified(&mut args.common, 1)?;
    let counters = CollatedMatcher::new_from_collated(&args, aln, bed, vcf, pos)?.process()?;
    print_routing_counters(&counters, "collated", &args.common);
    write_stats_if_configured(&counters, &args.common, n, "collated")
}
```

### Deprecation shim (backward compatibility)

```rust
// At the very top of main(), before Cli::parse():
// Rewrite legacy flat invocation to subcommand form.
fn maybe_rewrite_args() -> Vec<std::ffi::OsString> {
    let mut args: Vec<_> = std::env::args_os().collect();
    // Detect legacy: no subcommand as first non-flag argument.
    let first_positional = args.iter().skip(1)
        .find(|a| !a.to_string_lossy().starts_with('-'));
    let is_subcommand = first_positional.map(|a| {
        matches!(a.to_string_lossy().as_ref(),
            "namesorted" | "hashlookup" | "collated")
    }).unwrap_or(false);

    if !is_subcommand {
        // Extract --matching-algorithm value and inject as subcommand.
        let algo = args.windows(2)
            .find(|w| w[0] == "--matching-algorithm")
            .map(|w| w[1].to_string_lossy().into_owned())
            .unwrap_or_else(|| "namesorted".to_string());
        // Remove --matching-algorithm and its value from args.
        args.retain(|a| a != "--matching-algorithm");
        // Insert subcommand after argv[0].
        let sub = match algo.as_str() {
            "hashlookup" | "hash-lookup" => "hashlookup",
            "collated"                    => "collated",
            _                             => "namesorted",
        };
        tracing::warn!(
            "Legacy --matching-algorithm flag detected. \
             Please use 'xenofilters {sub} ...' instead. \
             The --matching-algorithm flag will be removed in v1.0."
        );
        args.insert(1, std::ffi::OsString::from(sub));
    }
    args
}
```
